# Personal Portfolio Website

A modern, responsive, and professional personal portfolio website built to showcase my skills, education, projects, resume, and technical profile.

This portfolio was developed as part of my **Web Development Internship at KodBud** and focuses on responsive design, interactive user experience, modern UI styling, and client-side functionality.

---

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Modern and professional user interface
- About Me section
- Education timeline
- Technical Skills section
- Project showcase
- Resume viewing and download
- Contact section
- GitHub and LinkedIn integration
- Dark mode
- Interactive navigation
- Smooth scrolling
- Scroll-to-top functionality
- Typing text animation
- Hover effects and CSS animations
- Responsive mobile navigation

---

## 🛠️ Technologies Used

- **HTML5** — Semantic webpage structure
- **CSS3** — Responsive design, animations, transitions, and modern UI styling
- **JavaScript** — DOM manipulation and interactive functionality
- **Font Awesome** — Icons
- **Google Fonts** — Typography
