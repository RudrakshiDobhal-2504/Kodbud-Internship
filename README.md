# KodBud Web Development Internship

A collection of web development projects completed during my **Web Development Internship at KodBud**.

These projects were developed to strengthen my practical understanding of frontend development, responsive design, JavaScript interactivity, form validation, and modern user interface development.

---

## 🚀 Projects

### 01. Personal Portfolio Website

A responsive and professional personal portfolio website designed to showcase my profile, skills, education, projects, resume, and contact information.

**Key Features**
- Responsive portfolio layout
- About, Education, Skills, Projects, and Contact sections
- Dark mode
- Interactive navigation
- Resume viewing and download
- Responsive design for desktop, tablet, and mobile
- Modern UI animations and hover effects

**Technologies**
- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

---

### 02. Google Homepage Clone

A responsive recreation of the Google-inspired homepage developed to practice frontend layout, styling, and JavaScript interactions.

**Key Features**
- Google-inspired navigation
- Search interface
- Search button interaction
- Voice search UI
- Image search option
- Navigation and footer links
- Responsive layout
- Interactive UI elements

**Technologies**
- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

---

### 03. Form Validation

A responsive contact form implementing client-side validation using JavaScript to provide meaningful feedback and improve the user experience.

**Key Features**
- Full name validation
- Email format validation
- Phone number validation
- Message validation
- Character count functionality
- Error messages and visual feedback
- Success feedback after valid submission
- Responsive design

**Technologies**
- HTML5
- CSS3
- JavaScript
- Google Fonts

---

### 04. Simple Blog Page

A responsive blog webpage created to practice content-based website design, structured layouts, navigation, and interactive frontend elements.

**Key Features**
- Blog article cards
- Article titles and descriptions
- Categories and publication information
- Read More interactions
- Navigation menu
- Search/interactive elements
- Responsive layout
- Modern card-based UI
- Hover effects

**Technologies**
- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts
